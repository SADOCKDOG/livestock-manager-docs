# livestock-manager-docs

Páginas públicas de [Livestock Manager](https://github.com/SADOCKDOG/LIVESTOCK-MANAGER) (guías de usuario y política de privacidad), servidas vía GitHub Pages en:

https://sadockdog.github.io/livestock-manager-docs/

Este repositorio es independiente y **no contiene el código fuente de la app** — solo el contenido HTML que necesita ser público (enlazado desde Google Play Console / Microsoft Partner Center). El código fuente vive en el repositorio privado `LIVESTOCK-MANAGER`.

## Actualizar contenido

Copiar manualmente los HTML actualizados desde `LIVESTOCK-MANAGER/docs/*.html` y `LIVESTOCK-MANAGER/privacy-policy.html` a `docs/` en este repo, revisar el diff y hacer commit.
